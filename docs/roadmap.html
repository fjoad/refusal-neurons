Refusal Neurons Roadmap

Kazemi et al. (2026) found one MLP neuron that gates safety refusal in English text. We are testing whether the same neuron gates refusal in other languages and modalities. First we replicate their paper, then we extend it to Arabic.

Where we are
Replication: the published neurons check out on all 3 models; our own search is written but not yet run
Arabic: the English neuron transfers (AUROC 0.954 vs 0.977)
Next: M2 acceptance run on panther

Milestones

The order agreed on 19 Oct. Each step gates the next. Numbers are rough until the judge is in place (refusal is string-matched on 30 prompts).

  1. 0

    Setup on panther

    Done

    refneu env, Qwen3-1.7B / 8B and Llama-3.1-8B cached, Arditi data splits (HarmBench 191 after overlap removal, matching the paper).

  2. 1

    M1 · Check the published neurons

    Done

    Take Apple's neuron IDs, measure harmful vs harmless separation, then pin the neuron and watch refusal drop.

    Qwen3-1.7B L13:F3270 AUROC 0.999 · Qwen3-8B L14:F7924 0.997 · Llama-3.1-8B L11:F4258 1.000. Pinning drives refusal to about 0 on all three.

  3. 1b

    Arabic teaser

    Done

    The English-found Qwen3-8B neuron on 100 parallel MultiJail prompts, English vs human-translated Arabic.

    Fires at the same token with the same strength (−3.10 Arabic vs −3.21 English). AUROC 0.954 vs 0.977. Pinning lowers refusal in both languages.

  4. 2

    M2 · Rediscover the neurons ourselves

    Code ready, not run

    Gradient × activation search over the first two-thirds of layers (written by Codex, checked against the paper). Pass: it finds L13:F3270 and L14:F7924 in its top 5. Still to build: the rerank, which sweeps the pin value m on HarmBench and keeps the best attacker.

  5. 3

    Pick one judge for every language

    Open

    Llama-Guard-3 likely doesn't cover Arabic. Options: an LLM judge (Claude, as Apple used) or translate responses to English and use Llama-Guard-3 or WildGuard. Run two on a sample, compare, pick.

  6. 4

    M3 · Full evaluation, English first

    Not started

    JailbreakBench ASR with the judge, constant and anchor interventions, MMLU and GSM8K cost, XSTest detection AUROC.

  7. 5

    Search in Arabic

    After M2

    Run the search on Arabic prompts. Same neuron, or a different one? This is the core question for Paper A.

  8. 6

    Modalities

    After Arabic

    Image and speech, using models that share a backbone with our text models, so "the same neuron" means the same layer and index.

Three papers, one codebase

Paper A · current focus

Across languages

Same neuron in Arabic? Same token? Does pinning still jailbreak? Does the search find the same neuron? Arabic only for now.

Paper B

Across modalities

The same questions for images of text and speech. Could merge with A if results are small.

Paper C

Neurons vs directions vs SAEs

Links our EMNLP paper, Kazemi et al. and Goodfire's "Already Clean" essay.

Settled decisions

  • Replicate first. Every direction depends on finding the neuron ourselves.
  • Three models, fp16 on V100. fp16 and fp32 gave identical results.
  • Arabic only for now. A full replication plus Arabic is already a paper.
  • Human-translated data. MultiJail and Aya, so translations can't be blamed.
  • One judge for every language. Otherwise English and Arabic numbers aren't comparable.

Open questions

  • Which judge? LLM judge vs translate-then-classify.
  • Which multimodal models share our backbones? Check before choosing.
  • Is MultiJail harmful enough? Baseline refusal is only about 0.45 by string match.

Recommendation

  1. Run the M2 acceptance test now. Two GPU jobs, already scripted. If the published neurons are in the top 5, our search works.
  2. Build the rerank and settle the judge while those jobs run.
  3. Do the core of M3: JailbreakBench ASR, anchor, MMLU/GSM8K and XSTest. Leave §3.2, §3.3, §3.5 and §4 for Paper C or skip them.
  4. Then the Arabic search, which is the first real result for Paper A.
